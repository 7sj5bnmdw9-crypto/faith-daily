# Faith Daily PWA

This is a phone-friendly Progressive Web App.

Features:
- Full 66-book Bible navigation
- KJV chapter reader through Bible-API
- Verse of the Day
- Bible study plans
- Christian motivation
- Dark mode
- iPhone Home Screen / standalone PWA support

## Run it
A PWA needs to be served over HTTPS (or localhost). The easiest route is to upload this folder to a static host such as GitHub Pages, Netlify, Vercel, or Cloudflare Pages.

On iPhone Safari:
1. Open the hosted site.
2. Tap Share.
3. Tap "Add to Home Screen."
4. Tap Add.

Before a public release, verify the Bible API's current terms and add a properly licensed/offline Bible source if needed.
